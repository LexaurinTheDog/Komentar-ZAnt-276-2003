# Komentář k zákonu č. 276/2003 Sb., o Antarktidě a o změně některých zákonů

Otevřený komentář k zákonu o Antarktidě — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; zásady ochrany a využívání Antarktidy, povolení činností, posuzování vlivů na životní prostředí, ochrana fauny a flóry, nakládání s odpadem, ochrana moře, státní správa, kontrola a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2003-00276_2025-07-01`.
